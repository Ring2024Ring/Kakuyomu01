## 別のPCから再開する

### Codexのクラウド環境で作業する場合

1. 別のPCで、同じアカウントのCodexにログインします。
2. GitHub連携で `Ring2024Ring/Kakuyomu01` を選び、`main` ブランチから作業を開始します。
3. このREADMEと、GitHubに保存した最新ファイルを読み込んで作業を続けます。
4. 作業後は変更をコミットし、GitHubにプッシュします。別ブランチで作業した場合は、変更を `main` に取り込んでからPCを切り替えます。

プロジェクトのファイルはGitHubから取得できます。チャットの履歴や各PCのローカル設定はGitリポジトリには含まれません。次に必要な作業や決定事項もファイルに記録しておくと、別のチャットでも続けられます。

### PC内のフォルダで作業する場合

GitHub Desktopを使うと、コマンドを入力せずに同期できます。

1. GitHub Desktopをインストールし、保存先にアクセスできるGitHubアカウントでログインします。
2. `File` → `Clone repository` で `Ring2024Ring/Kakuyomu01` を選び、PC内の保存場所を指定します。
3. Codexで、取得した `Kakuyomu01` フォルダをプロジェクトとして開きます。
4. 作業前にGitHub Desktopで `Fetch origin` を実行し、更新があれば `Pull origin` で取り込みます。
5. 作業後は変更内容を確認してコミットし、`Push origin` でGitHubに保存します。

Gitを使える場合は、初回に次のコマンドでも取得できます。

```sh
git clone https://github.com/Ring2024Ring/Kakuyomu01.git
cd Kakuyomu01
```

同じフォルダで作業を再開するときは、編集前に更新を取り込みます。

```sh
git pull --ff-only
```

## 今のPCにあるファイルを追加する

1. 上の手順でリポジトリを取得します。
2. 既存の原稿やコードを、その `Kakuyomu01` フォルダへコピーします。
3. GitHub Desktopで追加されたファイルを確認し、コミットして `Push origin` を実行します。
4. 別のPCで `Pull origin` を実行し、追加したファイルを取得します。

このリポジトリは現在公開されています。未公開原稿などを追加する場合は、GitHubで公開範囲を確認してください。APIキーやパスワードを含むファイルは保存しないでください。

## PCを切り替える前に

- 作業ファイルを保存する。
- 変更をコミットし、GitHubへプッシュする。
- 次に行う作業や決定事項を、このREADMEなどに追記する。
- 次のPCでは、編集する前に最新の変更を取り込む。

同じファイルを両方のPCで同時に編集すると、変更の統合が必要になることがあります。PCを切り替えるたびに、プッシュとプルを行ってください。
